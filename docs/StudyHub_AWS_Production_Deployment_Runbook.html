7. Complete Troubleshooting Log & Fixes Applied

⚠️ 1. SSH Connection Timeout
Cause: EC2 was launched in a private subnet route table with no IGW route.
Solution: Associated subnet with studyhub-public-rt (Internet Gateway route).
⚠️ 2. Next.js Monorepo Standalone Output
Cause: Next.js builds failed in Docker without standalone directory.
Solution: Added output: 'standalone' in apps/web/next.config.ts and apps/admin/next.config.ts.
⚠️ 3. Memory Spikes & SSH Resets During Builds
Cause: Next.js compilations across 4 containers consumed 100% CPU/RAM.
Solution: Created a 4GB Swap file (/swapfile), added SSH keepalive, and built sequentially.
⚠️ 4. Admin Docker Build Missing public/ Folder
Cause: apps/admin lacked a public folder, breaking Docker COPY.
Solution: Added RUN mkdir -p apps/admin/public and created .gitkeep.
⚠️ 5. Prisma 7 Build-Time Generate Failure
Cause: Prisma 7 requires DATABASE_URL even during client generation.
Solution: Passed dummy DATABASE_URL="postgresql://build:build@localhost:5432/build".
⚠️ 6. Node 24 ESM Module Resolution (API & Worker)
Cause: Node 24 strictly requires .js extensions on compiled relative imports.
Solution: Configured Dockerfiles to launch via npx tsx --tsconfig ....
⚠️ 7. Missing package.json in Runtime Container
Cause: Omitted root package.json, breaking npm workspace resolution.
Solution: Added COPY --from=build /app/package.json /app/package-lock.json ./.
⚠️ 8. RDS PostgreSQL Port 5432 Inbound Rule
Cause: RDS Security Group blocked EC2 private IP (10.0.87.55).
Solution: Added Inbound Rule for PostgreSQL 5432 from VPC CIDR 10.0.0.0/16.
⚠️ 9. Route Prefix Mismatch (/auth/login vs /api/v1/auth/login)
Cause: Frontend called /auth/login while backend mounted at /api/v1/auth/login.
Solution: Mounted routes at both /api/v1 and /, and normalized client config URLs.
⚠️ 10. AWS RDS SSL Connection Rejection (no encryption)
Cause: AWS RDS strictly requires SSL; node-postgres attempted unencrypted connections.
Solution: Enabled automatic SSL (ssl: { rejectUnauthorized: false }) in packages/database/src/client.ts.
⚠️ 11. Missing User.avatarUrl Column
Cause: avatarUrl was in schema but had no migration generated.
Solution: Created migration 20260824000000_add_avatar_url and added safe check to seed script.
⚠️ 12. Missing STUDENT Role & Admin 403 Forbidden Errors
Cause: Database was missing STUDENT role and ROLE_PERMISSION_MANAGE permissions for ADMIN.
Solution: Enhanced seed-admin-user.ts to bootstrap all 3 roles, 26 permissions, and grant full RBAC to Admin.
